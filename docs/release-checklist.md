## 二、必须你来做（我做不了）

### 1. 华为开发者账号 + 实名认证

上架的前提。个人开发者需实名；**发布应用通常还需要软著或电子版权认证**，
这一步耗时最长（可能数周），建议最先启动。

### 2. 在 AppGallery Connect 创建应用

- 进入 AGC → 我的应用 → 新建 HarmonyOS 应用
- **包名（bundleName）一旦创建不可更改**，且必须与代码里一致
- 当前代码里的包名是 `dev.yan.yan_note` ← **这一项需要你确认**

> 华为要求 bundleName 不可缺省，且惯例是**你自己拥有的域名反写**。
> `dev.yan` 不是你的域名。如果 AGC 拒绝这个包名，就得改，
> 而改包名要同步改 `app.json5`、`ohos/build-profile.json5` 与所有引用。
> **先确认包名能否通过，再往下做。**

### 3. 发布签名证书

调试签名不能用于上架。需要：
- 在 AGC 申请**发布证书**（.cer）与 **Profile**（.p7b）
- 在 DevEco 里配置 `signingConfigs`（当前是空数组）
- 或让 DevEco 自动生成后导出

有了它才能产出 `entry-default-signed.hap`

### 4. 真机验证

我这边只有模拟器。上架前至少要在**一台真机**上跑通：
打开库 → 编辑 → 预览 → 搜索 → 保存。模拟器不能替代。

### 5. 商店素材

| 素材 | 要求 | 状态 |
|---|---|---|
| 应用图标 | 需按官方素材规范（分层图标等） | 已有 1024 母图，可按规范导出 |
| 应用截图 | 各机型多张 | 有模拟器截图可用，建议真机重拍 |
| 应用介绍 / 一句话简介 | 文案 | 可从 README 提炼 |
| 隐私政策 | **必须**，且需可访问的 URL | ❌ 还没有 |

隐私政策这一项别漏 —— 纯本地应用也要有（说明"不收集任何数据"）。

### 6. 上架前自检

AGC 有自动检测，常见驳回项：
- bundleName 缺失或不合规
- 图标不符合素材规范
- 权限与实际功能不符（我们已清空权限，这一项应该没问题）
- 缺少隐私政策

## 三、鸿蒙端的已知限制（上架前要知道）

| 限制 | 影响 |
|---|---|
| OHOS 端拿不到命令行参数 | `--library` / `--open` 在鸿蒙上无效。已兜底为"启动直接打开沙箱库"，桌面端不受影响 |
| 目录选择是「选文件并复制进沙箱」 | 不是原地编辑。用户改的是沙箱副本，**不是原始文件** |
| 无法选目录 | `DocumentViewPicker` 只支持选文件、不支持选目录 —— "选一个文件夹原地读写"在这个 API 下做不到 |
| 无 `url_launcher` 鸿蒙实现 | 预览里点外部链接不会打开浏览器 |
| 无 `file_picker` 鸿蒙实现 | 「打开文件夹作为库」按钮在鸿蒙上无效（已用"启动即打开沙箱库"兜底） |

> **第一条要特别注意**：上架文案不能写"直接编辑你的 Markdown 文件"，
> 准确的说法是「**导入到应用内编辑，改完可导出回原位置**」。
> 闭环是：导入 → 沙箱内编辑 → 导出回去（已实现 `exportFile`）。

### 已在模拟器上验证过的

- 构建、安装、启动
- 顶栏避让系统状态栏；移动端布局（文件树抽屉 + 底部源码/预览切换器）
- 应用名「砚」与图标
- 启动自动打开沙箱库（`yan-library · 纯文件库`）
- 系统文件选择器弹出
- 偏好存储插件注册成功
- **新建笔记**（由作者在模拟器上手动确认）

### 未验证

- 真机（本机没有设备）
- 预览里点外部链接（受 `url_launcher` 缺失影响）

## 四、建议的顺序

1. **确认包名**（`dev.yan.yan_note` 能否过 AGC）
2. 启动开发者认证 / 软著（最长的一条）
3. 决定沙箱复制 vs 原地读写（影响上架文案）
4. 配发布签名 → 出 signed HAP
5. 真机验证
6. 准备素材 + 隐私政策 → 提审
