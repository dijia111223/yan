# 示例库 · Sample Library

这个文件夹的用途：**把它当作一个"库"打开，就能立刻看到砚的全部 v1 功能在真实文件上的表现。**

## 怎么用

1. 启动砚；
2. 点击「打开文件夹作为库」（或按 `Ctrl+O`），选中本文件夹（`app/assets/sample`）；
3. 左侧会出现三篇示例笔记，点开任意一篇，右边就是 GFM 预览。

## 里面有什么

| 文件 | 覆盖的能力 |
|---|---|
| `欢迎使用砚.md` | frontmatter、标题层级、表格、代码块高亮、行内/行间公式、任务列表、引用、链接 |
| `读书笔记示例.md` | frontmatter 的 `source` / `tags` 字段、长文排版 |
| `考研笔记示例.md` | 任务列表、公式密集的数学笔记形态 |

## 说明

这些文件就是普通的 Markdown 文件。**没有任何私有格式、没有任何数据库**——
你可以直接用记事本打开它们，也可以把它们放进 Git 仓库做版本管理（v1 的同步方案就是 Git）。
